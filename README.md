# 🎬 TMDB-TOP300 电影榜单数据统计与可视化

本项目基于 TMDB 平台 TOP300 电影榜单数据，使用 Python 进行数据清洗与多维度的探索性数据分析（EDA），并通过 Matplotlib 绘制组合图表，直观呈现电影行业的发展趋势、语种分布、类型偏好及评分状况。

## 📊 核心分析维度

本项目通过四个主要需求完成了数据洞察：

1. **每年电影数量变化（折线图）**：
   - 针对“年份”字段存在缺失值的问题，通过提取“上映时间”的前四位进行填补。
   - 统计每年上榜电影的数量，绘制折线图，观察电影产出的时间周期变化。
2. **不同语言电影数量（柱状图）**：
   - 使用 `groupby` 降序排列各语种上榜电影数量，分析英语及其他语种的市场占比。
3. **不同类型电影数量（柱状图）**：
   - 由于单部电影包含多个类型（如“剧情, 犯罪”），通过字符串分割与遍历循环进行“一对多”打散重组，统计各类型（剧情、动作、喜剧等）的频次。
4. **不同评分电影占比（饼状图）**：
   - 统计各评分的数量分布。为了提升图表可读性，**将数据占比小于 2% 的评分合并为“其他”**，避免饼图碎片化。

## 🛠️ 技术栈

- **编程语言**：Python 3
- **数据分析**：Pandas, NumPy
- **数据可视化**：Matplotlib (使用 `subplots` 绘制 2x2 画布)
- **运行环境**：Jupyter Notebook
